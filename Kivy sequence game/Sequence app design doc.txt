Sequence app design doc

mvp:
- menu with 'play' and 'scores' buttons - DONE
- timer counting down that can be converted into score - DONE
- generic sequence game template that can be adapted into a number of different styles of presentation - DONE
- 3 character 'name' input
- button presses give feedback, incorrect choices turn red, correct choices turn green, a sequence must be succesfully completed to go on to next stage
- 4 stages with a win state at the end - DONE
- win state records score & name to file
- fail state occurs when timer runs out, no score recorded - DONE
